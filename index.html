01 / ABOUT THE LAB


犯罪現象を認知と脳を中心とした多水準から捉え、水準間のつながりと、時間的推移・犯罪する／しないの分岐を科学的に解明する。

02 / RESEARCH


Six interconnected levels.

LEVEL 01

発達的文脈

どのような背景のもとで育ったか

小児期逆境体験（ACEs） / 小児期肯定体験（PCEs） / 発達障碍 / 家族 / 学校 / 地域社会
LEVEL 02

社会的経験

他者や社会との間で何を経験したか

恋愛関係の破綻 / 挫折・裏切り / 社会的排斥 / 対人ストレス / 仲間からの影響 / 差別経験
LEVEL 03

感情・認知

経験をどのように受け止め、意味づけるか

感情制御 / 復讐 / シャーデンフロイデ / 先入観 / 隠蔽 / 応報的動機 / 責任帰属 / 犯罪性知覚 / 行為主体感
LEVEL 04

脳・身体

心の働きが脳・身体にどのように現れるか

脳血流動態反応 / 脳機能ネットワーク / 心拍変動 / 皮膚電気反応 / 呼吸 / 内受容感覚
LEVEL 05

行動

どのようにその人の実際の行動と結びつくのか

犯罪準備行動 / 殺人 / ストーキング / 恋人間暴力 / 性犯罪 / リスク・テイキング / 逸脱行動
LEVEL 06

社会的帰結

どのように社会的問題へつながっていくのか

テロリズム / 被害者排斥 / 犯罪不安 / 脆弱性 / 厳罰化 / 量刑判断 / 保護観察 / 更生支援
